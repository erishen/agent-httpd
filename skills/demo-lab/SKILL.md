# demo-lab：服务器体检

这是一条开箱即用的演示 Skill（skills/demo-lab/SKILL.md）。当你被要求
"运行 demo-lab 技能" 时，按下面步骤执行，回复以一行标记开头：

1. 输出第一行：`[demo-lab skill] 服务器体检报告`
2. 调用 `get_time`，记录服务器当前本地时间。
3. 调用 `read_file`（path 填 `index.html`）读取服务器主页源码。
4. 用一句话总结主页里的关键信息（标题 / 路由 / 技术栈字样）。
5. 最后用列表给出体检结论：时间同步、主页可读、工具链路可用。

严格遵守以下约束：
- 必须真实调用工具，不得凭记忆编造文件内容。
- 不要修改任何文件，只读。
- 若某个工具调用失败，把失败原因写进"异常"小节后继续，不要中止。
